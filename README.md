# docs-tango -- the Tango FPGA guides

**Version 2026-10-30** (date code `20261030`)

The guides for **Tango FPGA**, the FPGA cores, framework and firmware for the **Sipeed Tang Console 138K**, are in
this repository's **[wiki](https://github.com/Tango-FPGA/docs-tango/wiki)**: setting up the board, using the menus, and
building cores.

This repository itself holds only this README and the licence of the guides' text. Reference facts about each
component (installing, building, its files, its licence) are in that component's own README, and the guides link to
them.
